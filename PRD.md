# PRD — CRM4Max

## 1. Обзор продукта

**Название:** CRM4Max
**Платформа:** Мессенджер Max (мини-приложения VK)
**Целевая аудитория:** ИП и самозанятые в сфере красоты — мастера маникюра, парикмахеры, стилисты, барберы
**Цель:** Дать мастерам инструмент для онлайн-записи клиентов прямо через Max, без сторонних сервисов

### Демо-ссылки

- **Клиент к Анне Смирновой:** `https://max.ru/id9706002253_1_bot?startapp=ee5e98b7-0a08-4a01-bc38-4e3efaf165d7`

---

## 2. Проблема

Мастера красоты (особенно самозанятые) управляют записями вручную — через личные сообщения, голосовые, таблицы. Это приводит к:
- Потере клиентов из-за неудобства записи
- Накладкам в расписании
- Забытым визитам без напоминаний
- Ручному контролю оплат

---

## 3. Решение

Два мини-приложения в Max:
- **Мастер** — личный кабинет: управление расписанием, услугами, записями и платежами
- **Клиент** — запись на услугу в несколько кликов прямо в мессенджере

---

## 4. Пользователи

### Мастер (Самозанятый / ИП)
- Работает один или в небольшом салоне
- Принимает записи в мессенджерах
- Хочет автоматизировать запись и напоминания
- Получает оплату наличными или переводом

### Клиент
- Пользователь Max
- Хочет быстро записаться к мастеру
- Ожидает напоминание о визите

- [x] Создание/редактирование/удаление категорий (фото, название, описание)

### 5.2 Мини-приложение клиента

#### Карточка мастера (точка входа: `?masterId=xxx`)

- [x] Таб «Фото»: сетка примеров работ (workPhotos)
- [x] Таб «Отзывы»: список отзывов с рейтингом и текстом

- [x] Фильтр по конкретному дню (клик по дате в сетке)
- [x] Бейдж с количеством предстоящих записей на иконке таба

#### Детали записи
- [x] Бейдж статуса оплаты: НЕ ОПЛАЧЕНО (красный) / ДЕПОЗИТ (оранжевый) / ОПЛАЧЕНО (зелёный)
- [x] 4 кнопки действий: перенести / редактировать / написать мастеру / отменить (красная)
- [x] Перенос: inline calendar + слоты
- [x] Отмена: bottom sheet с правилами возврата депозита
- [x] «Оплатить» (синяя кнопка снизу)

#### Нижняя навигация
- [x] Каталог (`/`) / Записи (`/my-bookings`) / Сообщения (`/messages`) / Контакты (`/contacts`)
- [x] Бейдж с количеством предстоящих записей на «Записи»

## 6. Нефункциональные требования

| Требование | Описание |
|---|---|
| Производительность | Ответ API ≤ 300 мс для 95% запросов |
| Доступность | Uptime ≥ 99.5% |
| Безопасность | Авторизация через VK Silent Auth, HTTPS, JWT с ролями |
| Масштабируемость | Архитектура рассчитана на 10 000+ мастеров |
| Уведомления | Доставка напоминаний в течение 1 минуты от запланированного времени |
| Файлы | Все медиафайлы хранятся в S3-совместимом хранилище, не в БД |

## 7. Интеграции

| Сервис | Назначение |
|---|---|
| Max / VK Auth | Авторизация мастера и клиента (VK Silent Auth → JWT) |
| VK Pay | Приём депозитов и оплат |
| Max Bot API | Уведомления клиентам и мастерам |
| S3 (AWS / Yandex / MinIO) | Хранение фото профилей, категорий, услуг, примеров работ |

## 9. Статусы записи

```
PENDING → CONFIRMED → COMPLETED
   └─────────────────→ CANCELLED
```

| Статус | Описание |
|---|---|
| PENDING | Запись создана, ожидает подтверждения |
| CONFIRMED | Запись подтверждена мастером |
| COMPLETED | Визит состоялся |
| CANCELLED | Запись отменена (мастером или клиентом) |

---

## 10. Статусы оплаты

| Статус | Клиент видит | Описание |
|---|---|---|
| UNPAID | НЕ ОПЛАЧЕНО (красный) | Оплата не получена |
| DEPOSIT_PAID | ДЕПОЗИТ (оранжевый) | Внесён депозит |
| PAID | ОПЛАЧЕНО (зелёный) | Оплачено полностью |

---

## 11. Уведомления через Max Bot

| Событие | Получатель | Содержание |
|---|---|---|
| Новая запись | Мастер | Услуга, дата, время, имя клиента |
| Новая запись | Клиент | Услуга, дата, время, адрес мастера |
| Перенос | Клиент | Новая дата и время |
| Отмена | Клиент | Дата отменённой записи |
| Напоминание (cron, за 24 ч) | Клиент | Завтра в [время] — [услуга] |

Клиент может включить/выключить напоминание за 1 час через тоггл на экране выбора времени.

## 12. Что не входит в v1

- Мультимастерность (несколько мастеров одного салона)
- Полная онлайн-оплата (только депозит)
- Программа лояльности и купоны
- Аналитика и отчёты
- Интеграция с налоговой (самозанятые)
- Мобильное приложение вне Max
